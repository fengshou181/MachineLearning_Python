# 复现指南

本文档记录如何在本地环境完整复现本项目的所有算法运行结果。

## 1. 环境准备

### Python 版本

```
Python 3.11 (推荐 Anaconda)
```

### 依赖安装

```bash
pip install numpy==1.26.4 scipy==1.13.1 scikit-learn==1.5.1 matplotlib==3.9.2 flask
```

> 说明：原项目依赖的是 2016 年的旧版库，现代库下有 4 处兼容性问题已修复（见 `docs/知识库.md` 的「复现兼容性修复记录」）。

## 2. 一键运行所有脚本

项目根目录下的 `run_all.py` 会依次执行全部 13 个脚本并保存结果图：

```bash
python run_all.py
```

脚本做了三件事：
1. 设置 `MPLBACKEND=Agg`（无显示环境下绘图）
2. monkeypatch `plt.show` → 自动 `savefig('result_XX.png')`
3. 依次导入并执行各模块脚本

运行结束后，每个模块目录下会生成 `result_01.png`、`result_02.png` 等结果图。

## 3. 单独运行某个算法

```bash
# 线性回归
python LinearRegression/LinearRegression.py

# 逻辑回归（含 OneVsAll）
python LogisticRegression/LogisticRegression_OneVsAll.py

# BP 神经网络
python NeuralNetwok/NeuralNetwork.py

# SVM
python SVM/SVM_scikit-learn.py

# K-Means
python "K-Means/K-Menas.py"

# PCA
python PCA/PCA.py

# 异常检测
python AnomalyDetection/AnomalyDetection.py
```

## 4. 启动结果展示网站

```bash
python web_app.py
```

浏览器打开 http://127.0.0.1:5050 即可查看所有算法的结果图画廊。

## 6. 常见问题

**Q: 运行脚本报 `ModuleNotFoundError: No module named 'scipy.misc'`**
A: 已修复，改用 `plt.imread`。

**Q: 运行脚本报 `Reshape your data either using array.reshape(-1, 1)...`**
A: 已修复，sklearn 要求 2D 输入，已改为 `[[1650, 3]]`。

**Q: 运行后没有弹出图片窗口**
A: `run_all.py` 使用 Agg 后端，图片直接保存为 `result_*.png`，不会弹窗。单独运行脚本时若需要弹窗，去掉 `MPLBACKEND=Agg` 设置即可。
