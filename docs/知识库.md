## 算法模块详解

### 01 线性回归

**核心思想**：用一条直线拟合数据点，使预测值与真实值的平方误差最小。

**代价函数**：
```
J(θ) = (1/2m) Σ (hθ(x⁽ⁱ⁾) - y⁽ⁱ⁾)²
```
其中 `hθ(x) = θ₀ + θ₁x₁ + θ₂x₂ + ...`

**优化方法**：梯度下降（Gradient Descent）
```
θⱼ := θⱼ - α (1/m) Σ (hθ(x⁽ⁱ⁾) - y⁽ⁱ⁾) xⱼ⁽ⁱ⁾
```

**关键实现**：
- `computerCost(X, y, theta)`：计算代价
- `gradientDescent(X, y, theta, alpha, num_iters)`：批量梯度下降
- `featureNormaliza(X)`：均值归一化（加速收敛）

**结果指标**：
- 学习率 α = 0.01，迭代 1500 次
- 代价随迭代单调下降并收敛
- scikit-learn `LinearRegression` 对照验证

**结果图**：`LinearRegression/result_01.png`（代价曲线）、`result_02.png`（拟合直线）

### 02 逻辑回归

**核心思想**：用 S 型函数（sigmoid）将线性输出映射到 [0,1] 概率，实现二分类；通过 OneVsAll 扩展到多分类。

**S 型函数**：
```
g(z) = 1 / (1 + e⁻ᶻ)
```

**代价函数**（交叉熵）：
```
J(θ) = -(1/m) Σ [y⁽ⁱ⁾log(hθ(x⁽ⁱ⁾)) + (1-y⁽ⁱ⁾)log(1-hθ(x⁽ⁱ⁾))]
```

**正则化**：在代价函数后加 `(λ/2m) Σ θⱼ²`（j 从 1 开始）

**关键实现**：
- `sigmoid(z)`：S 型函数
- `costFunction` / `gradient`：正则化代价与梯度
- `mapFeature(X1, X2)`：多项式特征映射（degree=3）
- `oneVsAll(X, y, num_labels, λ)`：一对多分类
- 使用 `scipy.optimize.fmin_bfgs` 拟牛顿法优化

**结果指标**：
- 二分类（data1/data2）：决策边界可视化
- OneVsAll 手写数字识别：**准确率 96.48%**
- scikit-learn `LogisticRegression` 对照

**结果图**：`LogisticRegression/result_01.png`、`result_02.png`

### 03 BP 神经网络

**核心思想**：三层前馈网络（输入层→隐藏层→输出层），通过反向传播（Backpropagation）计算梯度并更新权重。

**网络结构**：
- 输入层：400 单元（20×20 像素手写数字）
- 隐藏层：25 单元
- 输出层：10 单元（数字 0-9）

**正向传播**：
```
a¹ = X  →  z² = a¹Θ¹ᵀ  →  a² = g(z²)  →  z³ = a²Θ²ᵀ  →  h = g(z³)
```

**反向传播**（误差递推）：
```
δ³ = a³ - y
δ² = (Θ²ᵀδ³) .* g'(z²)
Δᵢⱼ⁽ˡ⁾ += aⱼ⁽ˡ⁾ δᵢ⁽ˡ⁺¹⁾
```

**关键实现**：
- `nnCostFunction`：正则化代价函数
- `nnGradient`：BP 反向传播求梯度
- `checkGradient`：数值梯度检验（验证 BP 正确性）
- `randInitializeWeights`：权重随机初始化（打破对称性）

**结果指标**：
- 训练集预测准确度：**98.58%**
- 梯度检查通过（数值梯度与 BP 梯度一致）
- 隐藏层权重可视化

**结果图**：`NeuralNetwok/result_01.png`（100 个数字样本）、`result_02.png`（权重可视化）、`result_03.png`（准确度）

### 04 支持向量机

**核心思想**：在特征空间中寻找一个超平面，使两类样本的间隔（margin）最大；通过核函数处理非线性可分情况。

**代价函数**（hinge loss）：
```
J(θ) = C Σ [y⁽ⁱ⁾cost₁(θᵀx⁽ⁱ⁾) + (1-y⁽ⁱ⁾)cost₀(θᵀx⁽ⁱ⁾)] + (1/2) Σ θⱼ²
```
- C 越大 → margin 越大（对误分类惩罚越重）
- 核函数：Linear（线性）、RBF（高斯径向基）

**关键实现**：
- 使用 `scikit-learn.svm.SVC`
- 对比 linear 与 rbf 核的决策边界
- 对比不同 C / γ 参数下的分类效果

**结果指标**：
- 3 组数据集（data1/2/3）
- Linear 核：线性可分数据
- RBF 核：非线性决策边界

**结果图**：`SVM/result_01.png`、`result_02.png`、`result_03.png`

### 05 K-Means 聚类

**核心思想**：无监督聚类，迭代更新聚类中心使样本到所属中心的距离之和最小。

**迭代过程**：
1. 随机初始化 K 个聚类中心
2. 分配：每个样本归到最近的中心
3. 更新：中心 = 该簇所有样本的均值
4. 重复 2-3 直到收敛

**目标函数**：
```
J = Σ Σ ||x⁽ⁱ⁾ - μₖ⁽ⁱ⁾||²
```

**应用——图片压缩**：
- 将图片像素作为样本，K=16 聚类
- 用 16 个聚类中心代表所有像素颜色
- 实现 24-bit → 4-bit 颜色压缩

**关键实现**：
- 手写 K-Means 迭代过程
- `scikit-learn.KMeans` 对照

**结果指标**：
- K=3：模拟数据聚类
- K=16：小鸟图片压缩（bird.png）

**结果图**：`K-Means/result_01.png`（聚类过程）、`result_02.png`（图片压缩对比）

### 06 主成分分析

**核心思想**：降维。找到数据方差最大的方向（主成分），将高维数据投影到低维子空间，同时尽量保留信息。

**降维过程**：
1. 数据归一化（均值 0，方差 1）
2. 计算协方差矩阵 `Σ = (1/m) XᵀX`
3. 对 Σ 做特征值分解（SVD）
4. 取前 K 个特征向量构成投影矩阵 Ureduce
5. `z = Ureduceᵀ · x`

**数据恢复**：`x_approx = Ureduce · z`

**主成分个数选择**：保留 99% 方差，即
```
(Σᵢ₌₁ᵏ Sᵢᵢ) / (Σᵢ₌₁ⁿ Sᵢᵢ) ≥ 0.99
```

**关键实现**：
- 手写 PCA（SVD 分解）
- `scikit-learn.decomposition.PCA` 对照
- 2D→1D 演示 + 人脸数据集降维

**结果指标**：
- 2D 数据降维到 1D 并恢复
- 人脸数据集：降维后人脸仍可辨认
- 保留方差 ≥ 99%

**结果图**：`PCA/result_01~06.png`（降维过程、人脸数据集、恢复效果）

### 07 异常检测

**核心思想**：假设正常数据服从高斯分布，计算每个样本的概率密度 p(x)，概率低于阈值 ε 的判定为异常。

**高斯分布**：
```
p(x; μ, σ²) = (1/√(2π)σ) exp(-(x-μ)²/2σ²)
```

**算法步骤**：
1. 对每个特征计算 μⱼ 和 σⱼ²
2. `p(x) = Πⱼ p(xⱼ; μⱼ, σⱼ²)`（单元高斯，假设特征独立）
3. 用验证集的 F1 分数选择最优 ε
4. p(x) < ε → 异常

**阈值选择（F1 最大化）**：
```
precision = TP / (TP + FP)
recall = TP / (TP + FN)
F1 = 2·P·R / (P + R)
```

**关键实现**：
- 单元高斯分布（特征独立假设）
- 多元高斯分布（特征相关，自动捕捉协方差）
- 基于 F1 分数的阈值自动选择

**结果指标**：
- 最优阈值 ε = **8.99e-05**
- F1 分数 = **0.875**
- 异常点已在图中标记

**结果图**：`AnomalyDetection/result_01.png`（等高线 + 异常点）、`result_02.png`、`result_03.png`

## 复现兼容性修复记录

原项目代码写于 2016 年，依赖旧版库。在 Python 3.11 + 现代库环境下，4 个脚本需修复：

| 脚本 | 问题 | 修复 |
|---|---|---|
| `LinearRegression_scikit-learn.py` | sklearn 要求 2D 输入 | `[1650,3]` → `[[1650,3]]` |
| `K-Menas.py` | `scipy.misc.imread` 已移除 | 改用 `plt.imread` |
| `PCA.py` | `from sklearn.decomposition import pca` 导入不存在 | 删除无用导入 |
| `PCA_scikit-learn.py` | `pca` 类名已变 | 改为 `from sklearn.decomposition import PCA` |

**`run_all.py`** 一键运行脚本：
- 设置 `MPLBACKEND=Agg`（无界面环境）
- monkeypatch `plt.show` → 自动 `savefig`
- 依次执行 13 个脚本，结果保存为 `result_*.png`
